Funções de Ativação

Além do ReLU: ReLU, Sigmoid, Tanh, Softmax, Linear, Leaky ReLU, ELU e GELU — cada uma explicada com fórmula, curva, exemplos e analogia.

Funções de ativação são regras que cada neurônio aplica na sua saída. Sem elas, a rede neural seria apenas uma multiplicação de matrizes — incapaz de aprender padrões complexos.

Analogia geral Cada função é um porteiro com uma regra diferente para decidir quem entra e com que intensidade.
1

ReLU

Rectified Linear Unit
curva ReLU 
f(x) = max(0, x)
0 a ∞
  • Saída: 0 a ∞ — negativos viram zero, positivos passam direto
  • Uso: camadas intermediárias (ocultas) — é a mais comum
  • Vantagem: simples, rápida, converge bem na prática
Problema Neurônio morto — se um neurônio recebe valores negativos constantemente, o gradiente vira zero e ele para de aprender para sempre.
2

Sigmoid

curva Sigmoid 
f(x) = 1 / (1 + e-x)
0 a 1
  • Saída: sempre entre 0 e 1
  • Uso: camada de saída em problemas de sim/não (binário)
  • Interpretação: saída = probabilidade de ser a classe positiva
Analogia Dimmer de luz — qualquer sinal vira uma intensidade entre apagado (0) e totalmente aceso (1).
-2→0.12
0→0.50
2→0.88
Problema Gradiente desvanece nas camadas do meio — para entradas muito grandes ou muito pequenas, o gradiente fica quase zero e a rede para de aprender.
3

Tanh

Tangente Hiperbólica
curva Tanh 
f(x) = (eˣ - e⁻ˣ) / (eˣ + e⁻ˣ)
−1 a 1
  • Saída: sempre entre -1 e 1
  • Uso: camadas intermediárias quando valores negativos importam; RNNs e NLP
  • Vantagem sobre Sigmoid: centrada em zero — facilita o aprendizado
Analogia Balança de dois pratos — pode pender para negativo (-1) ou positivo (+1), com zero no equilíbrio perfeito.
-1→-0.76
0→0.00
1→0.76
4

Softmax

distribuição 
f(xᵢ) = eˣⁱ / Σ eˣʲ
soma = 1
  • Saída: vetor onde todos os valores somam 1 (distribuição de probabilidade)
  • Uso: camada de saída para múltiplas classes
  • Diferença do Sigmoid: Sigmoid → "chance de SIM"; Softmax → "dentre todas as opções, qual?"
Analogia Dividir uma pizza inteira entre as opções — a maior fatia é a classe mais provável. A soma das fatias é sempre 100%.
[2.0, 1.0, 0.5] → [0.60, 0.27, 0.13] soma = 1.0
5

Linear

sem ativação
curva Linear 
f(x) = x
−∞ a ∞
  • Saída: o próprio valor, sem nenhuma mudança
  • Uso: camada de saída em regressão — prever números contínuos (preço, temperatura)
  • Quando usar: quando a saída precisa ser qualquer número real
Analogia Porta aberta — tudo passa exatamente como chegou, sem filtro, sem transformação.
6

Leaky ReLU

Leaky ReLU 
f(x) = x          se x > 0
f(x) = 0.01 × x   se x ≤ 0
−∞ a ∞
  • Saída: -∞ a ∞ — negativos passam com apenas 1% da intensidade
  • Uso: alternativa ao ReLU quando neurônios mortos são um problema
  • Diferença do ReLU: negativos não viram zero — ficam com uma inclinação pequena
Analogia A peneira do ReLU, mas com furinhos minúsculos — os valores negativos não são completamente bloqueados, passam com 1% da força original.
-10→-0.1
5→5.0
7

ELU

Exponential Linear Unit
curva ELU 
f(x) = x             se x > 0
f(x) = α(eˣ - 1)    se x ≤ 0   (α = 1)
−∞ a ∞
  • Saída: -∞ a ∞ — negativos têm curva suave exponencial
  • Uso: alternativa mais suave ao Leaky ReLU
  • Vantagem: aprende mais rápido em alguns casos, saída negativa não vai para -∞
Nota A diferença entre ELU e Leaky ReLU está no lado negativo: Leaky ReLU usa uma reta (linear), enquanto ELU usa uma curva exponencial que se aproxima de -α assintoticamente.
8

GELU

Gaussian Error Linear Unit
curva GELU 
f(x) = x · Φ(x)
// Φ(x) = distribuição normal cumulativa
−∞ a ∞
  • Usada em: GPT, BERT, Claude e modelos de linguagem modernos
  • Ideia: pondera cada valor com base em probabilidade estatística
  • É uma versão "inteligente" do ReLU — decide se deixa passar com base em distribuição gaussiana
Analogia Se ReLU é um porteiro que diz "pode entrar ou não", GELU é um porteiro que diz "você pode entrar, mas vou decidir com base na probabilidade estatística de você ser útil".
Contexto GELU foi proposta em 2016 e hoje é a função padrão em modelos como GPT-2, GPT-3, BERT e Claude. A pequena "curva" no lado negativo (comparada ao ReLU) ajuda o gradiente a fluir melhor durante o treinamento.

Como Escolher

Regra de ouro Comece com ReLU nas camadas do meio e Sigmoid ou Softmax na saída. Só troque se tiver um problema específico.
